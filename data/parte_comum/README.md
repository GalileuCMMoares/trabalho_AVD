# Parte Comum — Obesity

Dataset escolhido para a Parte Comum: **Estimation of Obesity Levels Based On Eating Habits and Physical Condition** (*Obesity*).

- **Fonte:** [UCI Machine Learning Repository — Obesity (ID 544)](https://archive.ics.uci.edu/dataset/544)
- **Arquivo:** `ObesityDataSet_raw_and_data_sinthetic.csv`
- **Dimensões:** 2.111 instâncias e 17 atributos (8 numéricos, 8 categóricos e a variável alvo `NObeyesdad` com 7 classes de nível de obesidade).
